go-invoices-api
Go · Clean Architecture
Payment Reconciliation Service: matches incoming payments against issued invoices, computes invoice status, and keeps a full audit log. Built on Clean Architecture with PostgreSQL transactions and row-level locking.
What it demonstrates
  • Idempotent payment processing under concurrent access — row-level locking (SELECT ... FOR UPDATE) around every reconciliation transaction.
  • Invoice status computed from payment allocations (unmatched / partially paid / paid / overpaid), with a full audit trail of every discrepancy.
  • A small custom scheduler (`chronos`) for background reconciliation instead of pulling in a message broker.
  • Money stored as integer minor units to avoid floating-point errors in financial calculations.

Ant Colony
Go · real-time game server
Private repo
Browser ant-colony simulation. The player doesn't control the ants — they watch a colony forage, raise brood, dig tunnels and rooms, relocate its base, and go to war with neighboring colonies. All simulation logic runs on an authoritative Go server; the browser only renders and sends commands.
What it demonstrates
  • Single-goroutine authoritative game engine — no per-entity goroutines, no world mutex; state changes only through commands, immutable snapshots handed outward.
  • WebSocket protocol with snapshot + delta frames and compressed chunk streaming for a live, persistent world.
  • SQLite persistence with versioned snapshots plus a Redis hot cache — the simulation survives server restarts.
  • Deterministic seeded RNG, A*/flow-field navigation, and a full test suite run with -race.
