Избранные Go-проекты

Практические примеры кода
go-invoices-api
Go · Clean Architecture
Сервис сверки платежей: сопоставляет входящие платежи с выставленными счетами, вычисляет статус счёта и ведёт полный аудит-лог. Построен на Clean Architecture с транзакциями PostgreSQL и row-level locking.
Что показывает проект
  • Идемпотентная обработка платежей при конкурентном доступе — row-level locking (SELECT ... FOR UPDATE) вокруг каждой транзакции сверки.
  • Статус счёта вычисляется из распределения платежей (unmatched / partially paid / paid / overpaid), с полным аудитом каждого расхождения.
  • Небольшой собственный планировщик (`chronos`) для фоновой сверки вместо внешнего брокера сообщений.
  • Деньги хранятся в минимальных единицах валюты (целые числа), чтобы избежать ошибок плавающей точки в финансовых расчётах.
Ant Colony
Go · real-time game server
Приватный репозиторий
Браузерная игра-симуляция колонии муравьёв. Игрок не управляет муравьями — он наблюдает, как колония добывает еду, растит потомство, копает тоннели и комнаты, переносит базу и воюет с соседними колониями. Вся игровая логика — на authoritative Go-сервере, браузер только рисует и отправляет команды.
Что показывает проект
  • Авторитетный игровой движок в одной горутине — без горутины на муравья и без мьютекса вокруг мира; состояние меняется только через команды, наружу отдаются неизменяемые снапшоты.
  • WebSocket-протокол с snapshot + delta кадрами и сжатым потоком чанков для живого персистентного мира.
  • Персистентность в SQLite с версионными снапшотами плюс Redis hot cache — симуляция переживает рестарт сервера.
  • Детерминированный seeded RNG, A*/flow-field навигация, тесты гоняются с -race.
rats-langbot-tom
Go · Telegram · LLM
Приватный репозиторий
Telegram-бот для изучения языков: перевод (движки Yandex/Google), объяснение фраз через LLM (OpenRouter) и автогенерируемые квизы-опросы.
Что показывает проект
  • Интегрирует несколько внешних API из Go (OpenRouter LLM, Yandex Translate, Google Translate) за одним интерфейсом команд.
  • Структурированный вывод LLM (вопрос + варианты + ответ) парсится и превращается в нативный опрос Telegram.
  • Задеплоен на Fly.io — небольшой, реальный, всегда включённый AI-инструмент, а не демка.

AI Support CRM
Go · мультитенантный SaaS
Приватный репозиторий
Мультитенантная платформа бота поддержки (Telegram → WhatsApp) с базой знаний на RAG, эскалацией на менеджера и CRM-слоем поверх. White-label ядро для нескольких клиентов-бизнесов из одной кодовой базы.
Что показывает проект
  • Архитектура бэкенда на Go: мультитенантность через row-level security, RAG-пайплайн, фоновые задачи.
