Профиль

Честно: Python — не основной стек

Go и PHP — основной стек (10+ лет суммарно). Python нужен для скриптов, автоматизации и быстрых backend-сервисов, когда это лучший инструмент под задачу — сервис на FastAPI для обработки изображений, DNS-утилита для email-тулинга, разовая автоматизация в основных backend-ролях. Уровень Middle, прикладной, без глубины фреймворков.

Почему это подходит
  • Выпускаю реальный сервис на FastAPI end-to-end (не только скрипты/ноутбуки).
  • Спокойно читаю DNS/сетевые данные (MX, SPF, DKIM) и превращаю их в рабочий инструмент.
  • Использую Python там, где это реально быстрее, и иду дальше.
