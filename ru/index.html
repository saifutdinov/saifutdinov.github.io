Thread
Go · E2EE-чат
Чат со сквозным шифрованием для семьи и близких друзей, который запускается на вашем сервере: один Go-бинарь с SQLite, PWA на Preact, вход только по приглашениям, сообщения, медиа, звонки 1:1 и групповые. Сервер хранит только шифртекст. Open source (AGPL-3.0).
Что показывает проект
  • Собственная E2EE-схема на стандартных примитивах WebCrypto (ECDH/ECDSA P-256, AES-256-GCM, HKDF) с подтверждением устройств и кодами безопасности — и открыто описанными ограничениями (независимого аудита не было).
  • Realtime-ядро на Go: WebSocket-хаб, Web Push с шифрованным содержимым, звонки 1:1 по WebRTC с запечатанной сигнализацией и TURN, групповые звонки через LiveKit со сквозным шифрованием кадров.
  • Инженерия маленького сервера: работает на VPS с 1 ГБ — SQLite (WAL), пароли на argon2id, превью ссылок с защитой от SSRF, шифрованные ежедневные бэкапы в S3, метрики Prometheus.
  • Решения оформлены как ADR; тесты на Go и TypeScript, звонки проверяются в настоящем браузере, есть CI.
pdf-formatter
Go · редактор PDF
Редактор PDF, который работает на вашем компьютере и правит существующие документы аккуратно: изменённый блок переписывается прямо в потоке содержимого страницы, остальная страница остаётся байт в байт прежней. Построен на собственной PDF-библиотеке на Go (ISO 32000-1); есть сборки для macOS, Windows и Linux. Open source (AGPL-3.0).
Что показывает проект
  • Собственная PDF-библиотека на Go: парсер и запись, xref и объектные потоки, фильтры, шифрование (стандартный обработчик, ревизии 2–6), шрифты и CMap, встраивание TrueType, переписывание потоков содержимого, формы и закладки — около 21 тыс. строк Go и 24 файла тестов.
  • Неразрушающая модель: исходный файл не меняется, документ — это исходник плюс журнал операций, новый PDF — чистая функция от них, отмена убирает последнюю операцию.
  • Документы не покидают компьютер: сервер слушает только 127.0.0.1, а интерфейс и шрифты встроены в один исполняемый файл на платформу.
  • Выпускается релизами (.dmg для macOS, сборки для Windows и Linux); выходные файлы проверяются qpdf в тестовом образе.

go-invoices-api
Go · Clean Architecture
Сервис сверки платежей: сопоставляет входящие платежи с выставленными счетами, вычисляет статус счёта и ведёт полный аудит-лог. Построен на Clean Architecture с транзакциями PostgreSQL и row-level locking.

  • Деньги хранятся в минимальных единицах валюты (целые числа), чтобы избежать ошибок плавающей точки в финансовых расчётах.
routecheck
Python · CLI для диагностики сети
Утилита командной строки, которая отвечает на вопрос «почему этот IP доступен из одной страны или сети, но не из другой, и где именно ломается маршрут». Проверяет с вашего компьютера и из других стран, выясняет, чья это сеть и как она подключена к интернету, показывает маршрут как цепочку организаций и даёт вывод простыми словами. Только стандартная библиотека Python; лицензия MIT.
Что показывает проект
  • Ноль сторонних зависимостей: один файл на ~950 строк Python и 20 тестов, работает на Windows, macOS и Linux.
  • Объединяет открытые данные: пробы Globalping в других странах (ICMP и TCP с одних и тех же проб, поэтому результаты честно сравнимы), региональные регистраторы, несколько баз геолокации и их расхождения, данные RIPE RIS, точки обмена трафиком и статус RPKI.
  • Находит реальные причины: обрыв внутри сети цели, у соседа или на транзите; блокировка порта при исправном маршруте; потери из-за MTU; маршруты с невалидным RPKI или единственным провайдером; расхождение геобаз, из-за которого срабатывает ложный геоблок.
  • Прозрачна в том, что уходит наружу, и в собственных ограничениях.
