pdf-formatter
Go · PDF editor
A PDF editor that runs on your computer and edits existing documents surgically: the touched block is rewritten inside the page's content stream and the rest of the page stays byte-for-byte identical. Built on its own Go PDF library (ISO 32000-1); downloadable builds for macOS, Windows and Linux. Open source (AGPL-3.0).
What it demonstrates
  • Hand-written PDF library in Go: parser and writer, xref/object streams, filters, encryption (standard handler, revisions 2–6), fonts and CMaps, TrueType embedding, content-stream rewriting, forms and bookmarks — about 21k lines of Go with 24 test files.
  • Non-destructive model: the source file is never changed; a document is the source plus an operation log, the new PDF is a pure function of both, and undo removes the last operation.
  • Documents never leave the machine: the server listens on 127.0.0.1 only, and the interface and fonts are embedded into one executable per platform.
  • Shipped as releases (macOS .dmg, Windows and Linux builds); output files are verified with qpdf in the test image.

What it demonstrates

routecheck
Python · network diagnostics CLI
Command-line tool that answers “why is this IP reachable from one country or network but not from another, and where exactly does the route break?”. It checks from your machine and from other countries, shows who owns each network and how it is connected to the internet, draws the route as a chain of organisations and ends with a plain-language verdict. Python standard library only; MIT license.
What it demonstrates
  • Zero third-party dependencies: one ~950-line Python file with a 20-test suite, running on Windows, macOS and Linux.
  • Combines free open data: Globalping probes in other countries (ICMP and TCP from the same probes, so results compare fairly), regional registries, several geolocation databases and their disagreements, RIPE RIS views, IXPs and RPKI status.
  • Diagnoses real causes: a break inside the target network, at its neighbour or in transit; a blocked port vs. a healthy route; MTU loss; RPKI-invalid or single-upstream routes; geolocation disagreement behind false geoblocking.
  • Transparent about what leaves the machine and about its own limits.
